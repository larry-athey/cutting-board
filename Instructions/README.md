# Cutting Board Instructions

There's really not a lot to know about using the Cutting Board, calibrating the turntable and the sensor arm is about the full extent of it. Looking at the screen, you can see that that it is divided into four buttons plus a home button to the left of the screen, as well as two mechanical buttons to the left of the screen that function as Value+ and Value-.

Calibration is the absolute very first thing that you do with the Cutting Board so you don't cause damage to the sensor arm or run it off the end of its worm gear.
